# ProductParser 📦

Консольное приложение на C# (.NET 8), предназначенное для сбора данных (парсинга) с веб-страниц и сохранения их в удобном формате Excel.

## 🎯 О проекте

Этот проект создан как демонстрация практических навыков работы с HTTP-запросами, разбором HTML-кода и генерацией документов Excel. В качестве тестового полигона используется сайт [Books to Scrape](http://books.toscrape.com/) (специальная песочница для обучения парсингу).

Программа выполняет следующие действия:
1. Отправляет GET-запрос к указанному URL (имитируя реальный браузер).
2. Разбирает полученный HTML-код с помощью библиотеки `HtmlAgilityPack`.
3. Извлекает названия товаров (книг) и их цены.
4. Генерирует файл `products.xlsx` на рабочем столе пользователя с двумя колонками: «Название товара» и «Цена».

## 🛠️ Используемые технологии и пакеты

* **Язык и платформа:** C# / .NET 8.0
* **Сетевые запросы:** `HttpClient` с асинхронными вызовами (`async/await`).
* **Парсинг HTML:** [HtmlAgilityPack](https://html-agility-pack.net/) (использование XPath-селекторов для поиска элементов).
* **Работа с Excel:** [ClosedXML](https://github.com/ClosedXML/ClosedXML) (создание таблиц, автоширина колонок, сохранение в XLSX).

## 🚀 Как запустить

1. Клонируйте репозиторий на свой компьютер.
2. Откройте файл решения (`.sln`) в Visual Studio 2022.
3. Убедитесь, что NuGet-пакеты `HtmlAgilityPack` и `ClosedXML` успешно восстановлены.
4. Запустите проект, нажав **F5** (или кнопку «Пуск»).

После завершения работы программы в консоли появится сообщение об успехе, а на вашем рабочем столе будет создан файл `products.xlsx`.
